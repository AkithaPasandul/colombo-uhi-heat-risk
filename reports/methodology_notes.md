# Methodology notes
Log decisions + parameters as you go (feeds the chapter).

- AOI / CRS / grid: AOI is a fixed rectangular bounding box (W 79.8189, S 6.8618, E 79.8910, N 6.9821), not an administrative boundary — report all stats as "within study bbox," never "within Colombo Municipal Council." Target CRS EPSG:32644 (WGS84/UTM44N), 100m analysis grid. `config/config.yaml` originally had CRS=EPSG:5234 and mislabeled the AOI as "Colombo Municipal Council" — both fixed (2026-07-04); the underlying `data/external/cmc_boundary.geojson` geometry was already correct (a bbox rectangle), only its name/label was wrong.
- Reference grid (`src/grid.py`, 2026-07-04): AOI bbox reprojected to EPSG:32644, bounds snapped outward to the nearest 100m so the grid fully covers the AOI with no partial edge cells: xmin=369400, ymin=758600, xmax=377500, ymax=772000. Resulting grid is **81 x 134 cells (10,854 total)**, matching the expected ~80x130. Reference transform/shape lives at `data/interim/grid_reference.tif` (every `preprocess.py` reproject call targets this); the polygon grid (row/col-indexed, matching the raster's pixel grid) is at `data/processed/grid.gpkg`.
- Preprocessing / alignment (`src/preprocess.py`, 2026-07-04): all 7 rasters aligned onto `grid_reference.tif` in one `rasterio.warp.reproject()` call each. LST/NDVI/NDBI: bilinear, NaN passed as `src_nodata`. WorldCover: `Resampling.mode` in a single warp (mode-aggregate 10m->100m and reproject in one pass - GDAL's mode kernel picks the dominant class among overlapping source pixels, same result as aggregate-then-nearest, done jointly since this GDAL build (3.12.1) supports it directly). WorldPop: `Resampling.sum` to conserve population mass instead of averaging it away. GHSL: bilinear direct reproject from ESRI:54009 (native res already ~100m, no separate aggregation step needed). MODIS: copied at native 1km/EPSG:4326 with an explicit nodata tag, never resampled onto the 100m grid (`data/interim/modis_lst_native.tif`). Every aligned output has nodata set explicitly in its profile: -9999.0 for continuous/count layers, 255 for WorldCover (matching `grid_reference.tif`'s own sentinel convention). `land_mask` (`data/interim/land_mask.tif`) derived from aligned WorldCover: `True` where not water (class 80) and not nodata; fully defined for every cell, no nodata of its own.
  - Verification (all 5 checks passed): shapes all 134x81, nodata read back from disk matches the profile written; land fraction 53.45% land / 46.55% water (expected ~55%/45%); WorldPop mass raw=581,224.9 vs aligned=577,303.2, diff=0.67% (well within 1-2%); aligned LST over land cells only ranges 31.66-47.34 degC (within expected ~28-50); aligned WorldCover unique values = {10,30,40,50,60,80,90} - class 20 (shrubland) disappeared entirely after mode-aggregation, apparently never the dominant class in any 10x10 block of source pixels. Not a failure, just an expected side-effect of mode resampling on a minority class - worth remembering if any downstream code assumes all raw classes survive alignment.
- Feature table (`src/features.py`, 2026-07-04): 10,854 rows (one per grid cell), columns cell_id, x, y, lst, ndvi, ndbi, built_up, lulc_class, pop_count, pop_density, valid_lst, pop_valid, land_mask. No elevation/dist_water (no SRTM raster exported, only ever needed for the deferred ML layer). Aligned rasters' nodata sentinels (-9999.0 / 255) are converted to real NaN in the table so pandas ops don't need to remember raster-specific sentinels.
  - `land_mask` (confirmed, `src/preprocess.py:109`): `(worldcover_arr != 80) & (worldcover_arr != 255)` - already excludes both water AND the 99 nodata-edge cells in `worldcover_aligned.tif`; no fix needed.
  - Discovered data quirk: 604 cells are WorldCover water (class 80) but have valid WorldPop population data (`land_mask=False, pop_valid=True`) - not random noise, they cluster tightly in a narrow N-S band around x=372,400-374,500 (near-constant longitude spanning most of the AOI's height), almost certainly a Colombo canal/Beira-Lake-type feature where WorldPop's disaggregation model attributes population to fringing settlements along a water body WorldCover classifies as class 80. Genuine disagreement between the two source datasets, not an alignment bug. Doesn't affect downstream results: `land_mask` (not `pop_valid`) gates HEI/statistics, so these cells are correctly excluded regardless.
  - Land-only mean LST = 41.08 degC, vs combined (land+water) mean 36.13 degC, vs water-only mean 30.29 degC. The land-only mean is notably warmer than a naive "should be close to the raw combined mean" expectation - this is exactly the correction land-masking is for: ~47% of the AOI is cooler ocean/lagoon surface, which drags the combined mean down; excluding it legitimately raises the land-only mean. Read as confirmation the masking works, not a bug.
  - pop_density max = 479.4 people/cell on land (water cells top out at 161.7) - slightly below the raw raster's max of 518.8, consistent with sum-resampling redistributing some peak mass across reprojected cell boundaries.
  - Added `pyarrow` to requirements.txt (needed for `pandas.to_parquet`, wasn't listed originally).
- Heat Exposure Index (`src/hvi.py`, 2026-07-04): `HEI = minmax(lst_z * pop_density * (1-ndvi))`, `lst_z` z-scored from land cells only (mean=41.08, std=1.917 over land), `inv_ndvi` left unclipped (NDVI can go negative on bare/wet land, so `inv_ndvi` can exceed 1 - a legitimate value, not an error). `utils.minmax()` updated to guard against zero range (returns all-zero instead of NaN/inf) since the HEI plan explicitly called for this guard.
  - HEI is NaN wherever `land_mask`, `pop_valid`, or any of the three components is NaN - never computed from the remaining two. Valid cell count: land&pop_valid (5,415) minus the 24 boundary cells with NaN LST = **5,391** valid HEI cells; NaN count (5,463) matches this exclusion logic exactly, row-by-row.
  - HEI range confirmed exactly [0,1], no values outside. 45.54% of land cells (2,642/5,801) have negative `lst_z` (cooler than the land-wide mean) - expected, these correctly minmax toward ~0 rather than being excluded.
  - Top 10 HEI cells cluster tightly around 79.868E, 6.940N (UTM x~374850-375750, y~767050-767950) - central-north Colombo (Maradana/Kotahena/Grandpass area), LST 44.4-47.3 degC, pop_density 226-398 people/hectare. One coherent spatial hotspot, not scattered noise - a good plausibility signal.
  - Outputs: `outputs/tables/hei_by_cell.csv` (all 10,854 rows, NaN for excluded cells), `outputs/maps/hei.tif` (float32, nodata=-9999.0), `outputs/maps/hei_classified.tif` (5-class quantile, uint8, nodata=255).
- Hotspot analysis (`src/hotspots.py`, 2026-07-04): Queen contiguity weights built directly on the land+valid-LST polygon subset (5,777 cells) - not a distance band, since the analysis unit is a regular 100m grid and contiguity captures the natural raster adjacency without an arbitrary threshold (a ~150m band would give nearly the same result here, since diagonal neighbour distance is exactly 100*sqrt(2)=141.4m). 0 islands (every cell has >=1 neighbour); 4 disconnected components (sizes 5,748 / 20 / 7 / 2 - main landmass plus 3 small fragments cut off by water gaps).
  - Global Moran's I = 0.7978, p_sim=0.001 - strong, highly significant positive spatial autocorrelation in LST.
  - Getis-Ord Gi* (star=True, binary weights, two-sided permutation p-values, 999 permutations): uncorrected (p<0.05) hot=1,223 cold=694 ns=3,860; FDR-corrected (esda.fdr cutoff=0.0113) hot=873 cold=434 ns=4,470. FDR removes ~31.8% of naively-flagged cells - real but not overwhelming deflation, consistent with genuine signal (chance alone at alpha=0.05 over 5,777 tests would predict ~289 false positives, well below either count).
  - All 10/10 HVI top cells are also FDR-corrected Gi* hot spots (perfect overlap). Checked this isn't a formula artifact: HEI top-10 only overlaps 7/10 with a pure lst_z ranking, and lst_z vs pop_density are meaningfully negatively correlated (-0.61) across the broader HEI top-200, showing real trade-off dynamics exist. The perfect overlap at the extreme top is explained by the very strong global autocorrelation (I=0.80) plus this particular top-10 landing in one especially hot-and-dense pocket, not a bug.
  - Significant cold spots dominated by an eastern wetland/park cluster (~79.888E, 6.90-6.92N, likely Diyasaru/Beddagana wetland park in Kotte - WorldCover class 10 tree cover, NDVI ~0.82-0.84, LST ~31.7-32.5 degC at the extreme, 269/434=62% of all cold cells in this lon band including nearby cooler built-up cells), plus a smaller distinct coastal-strip cluster (14 cells, lon<79.833, WorldCover class 60 bare/sparse likely beach sand, mean LST 36.5 degC). Matches the expected "parks/wetlands/coastal strip" pattern.
  - Outputs: `outputs/tables/hotspots.csv` (all 10,854 rows; cell_id, x, y, lst, gi_z, p, label_raw, label - label=FDR-corrected, label_raw=uncorrected, NaN for cells outside the land+valid-LST analysis universe), `outputs/maps/hotspots.gpkg`.
- Validation (`src/validation.py`, 2026-07-04): Landsat-vs-MODIS aggregation groups every 100m cell (via lon/lat reprojection + the MODIS raster's own affine transform) into its native 1km MODIS block, then averages **land-only** pixels per block (never a naive all-pixel mean, which would reintroduce sea-surface mixing); blocks <50% land are dropped.
  - n=68 cells survive (land_fraction>=0.5 + valid MODIS + valid land LST) - only 1 less than the 69 previously-valid MODIS cells, **not "well below 69" as initially expected**. Investigated why: MOD11A2's own missingness pattern already has a median land_fraction of 1.0 and mean 0.94 among its 69 valid cells (MOD11A2 appears to already exclude ocean-dominant blocks at the source, being a land-surface product) - so the land-fraction filter is mostly redundant with masking MODIS already did internally, not a new independent constraint.
  - Pearson r=0.234 (p=0.055, borderline not significant), RMSE=7.29 degC. Weaker than one might hope - explained by MODIS's 1km resolution smoothing away the fine-scale urban heat variability Landsat resolves at 100m within a compact 8x13km AOI, plus likely differences in compositing methodology/overpass time between MOD11A2 and the Landsat dry-season composite. Framed as illustrative pattern-consistency, not a strong validation result - consistent with what the small, coarse MODIS sample was always going to allow.
  - Correlation matrix (land cells, n=5,801): lst-ndvi = -0.486 (moderate negative, as expected), lst-ndbi = +0.724 (strong positive, as expected), lst-built_up = +0.356 (positive but weaker - GHSL is a different-year/coarser-native-res product than NDBI, which is derived from the same Landsat composite as LST itself).
  - LST by land cover (land only): built-up (50, n=4,703) and bare/sparse (60, n=394) are hottest (mean 41.4/41.5 degC); tree cover (10, n=533) and grassland (30, n=135) cooler (38.6/39.3 degC); wetland (90, n=3) coolest (34.8 degC, but n=3 is too small to be reliable). Matches the hotspot analysis's cold-spot findings (tree cover/wetland cooler, built-up/bare hotter).
  - Outputs: `outputs/tables/validation.csv` (all 135 MODIS cells, `used_in_comparison` flag), `correlation_matrix.csv`, `lst_by_landcover.csv` (includes q25/median/q75 for boxplotting in `viz.py`).

- Port City reclamation area / dataset-year mismatch example (2026-07-04): the western reclaimed peninsula (~79.823-79.845E, 6.924-6.951N - the Colombo Port City land reclamation) is a concrete, checkable illustration of the raster year-mismatch limitation already noted above (LST/NDVI 2024 vs WorldPop 2020). Checked directly against `features.parquet`/`hotspots.csv` (516 land cells in that area): land cover is 73% bare/sparse (class 60) and 23% built-up (class 50), almost no vegetation; NDVI is near-zero (mean 0.13, median 0.10); Gi* shows a substantial hot-spot concentration there (101/516 = 20% significant hot, well above the background rate) consistent with bare reclaimed fill heating up; yet 153/516 cells (30%) carry non-trivial WorldPop-2020 population (mean 9.5, up to 43.7 people/hectare). Port City was still under active reclamation/early development around 2020 and has continued substantial construction since - so the population layer reflects a 2020 snapshot of a site whose physical footprint and land cover look markedly different by the 2024 LST/NDVI imagery. Good concrete example for the limitations section, beyond just stating the year mismatch abstractly.
- Date window + cloud notes: dry season 2024-01-01 to 2024-03-31. Raw data year mismatch across layers is a known limitation: LST/NDVI/NDBI 2024, WorldCover 2021, WorldPop/GHSL 2020 — framed as "most-recent-available composite," not a current-year snapshot.
- Index framing (exposure vs vulnerability): called "Heat Exposure Index (HEI)," not "Heat Vulnerability Index" — no socioeconomic/adaptive-capacity data is available.
- Land masking (required, not optional): ~45% of the bbox is ocean (WorldCover class 80, confirmed 45.1% of pixels). LST is valid (not nodata) over water (100% valid overall), so `lst_z`, correlations, LST-by-landcover stats, and Getis-Ord Gi* must all be computed over land cells only (`land_mask = worldcover != 80`), otherwise sea-surface temperatures bias the land z-scores. Water cells stay visible on raw LST/hotspot maps but are excluded from every statistic and from the HEI itself.

- HEI sensitivity analysis (`notebooks/03_hvi_experiments.ipynb`, 2026-07-04) — a genuine robustness check of three secondary design choices around the locked HEI formula, not a re-tuning of it:
  - (a) Normalisation (minmax vs. rank-based on `hei_raw`): Spearman = 1.000000, top-10 overlap 10/10, exactly. This is **mathematically guaranteed**, not an empirical finding — minmax and rank-based normalisation are both strictly monotonic transforms of the same `hei_raw`, so any two monotonic transforms of the same variable have identical rank order by construction. It confirms the choice is inconsequential for anything rank-based, but isn't itself evidence of robustness to a genuinely different design choice.
  - (c) Standardisation (standard mean/std z-score vs. robust median/IQR z-score for `lst_z`): Spearman = 0.997, top-10 overlap 10/10 (identical cells). Unlike (a), this is **not** guaranteed — it holds here because land LST is close to symmetric (mean 41.08 vs median 41.24 degC). This is the real empirical robustness evidence for the top-10/headline-cell finding, since it's an actual alternative estimator, not just a reparameterisation of the same score.
  - (b) Classification (quantile vs. equal-interval 5-class): only 29/1,078 (2.7%) of quantile's class-5 cells remain class-5 under equal-interval; equal-interval also collapses quantile classes 2, 3, and 4 into one bin, given the sharply right-skewed HEI distribution. **Framing**: quantile and equal-interval classification answer different questions — quantile asks "which cells rank in the top 20% for heat exposure" (relative prioritisation, appropriate for a planning-triage index), equal-interval asks "which cells cross an absolute HEI threshold" (only meaningful if that threshold has independent real-world meaning, which this normalised composite index doesn't have). Quantile is the correct choice for a planning-prioritisation index over a right-skewed distribution, not an arbitrary pick — but the sensitivity check is what actually establishes that **class membership** (not cell ranking) is what depends on this choice. The top-10 cell ranking itself is unaffected by classification method (classification is applied after ranking).
  - Net conclusion: the top-10/headline-cell finding is robust (real evidence: (c)'s 0.997 Spearman + 10/10 overlap; (a) is a guaranteed-not-empirical check). The class-5 spatial *pattern* is a property of the classification scheme as much as the data — worth a one-line caveat in the paper's methods section, not a redesign.
- Optional ML + XAI layer (`src/model.py`, `src/shap_analysis.py`, `notebooks/05_optional_ml_xai.ipynb`, 2026-07-11 — all intentionally untracked per `src/_MODEL_LAYER_NOTE.md`): a driver-attribution experiment supplementing (never replacing) the HEI/hotspot methodology. RF predicts land-cell LST from surface/population covariates; SHAP ranks what the model attributes predictions to.
  - Dataset = the exact HEI analysis universe (n=5,391 complete-case land cells) so the two analyses stay directly comparable. Raw x/y are never model features (with Moran's I=0.80 a tree would memorise location and launder autocorrelation as "importance"); they only build the 1km split blocks.
  - Spatial leakage controlled and quantified, not assumed away: whole-1km-block spatial split is the honest headline (75 blocks, 15 test); the naive random split is reported only to expose the leakage gap; block 5-fold GroupKFold gives the conservative stability number.
  - Two feature sets on identical splits (same seed; recomputed baseline rows reproduce the recorded baseline exactly — determinism check): **base** (cell-level ndvi/ndbi/built_up/pop_density + one-hot lulc) and **extended** (base + 3x3/300m NaN-aware focal means of the four continuous predictors + dist_water_m from a distance transform of land_mask). Focal features are predictor-only (never the LST target), so they cannot leak the target across block boundaries; dist_water_m realises the `dist_water` predictor from config.yaml's original optional_model list. Focal features inherit their parents' provenance — nothing new is measured, only 300m spatial context.
  - Results: baseline RF spatial-block R2=0.656 / RMSE=1.274 / MAE=0.976 degC; **extended RF (best optional model, replaces the original as such — the original stays in ml_metrics.csv as the frozen baseline) R2=0.765 / RMSE=1.054 / MAE=0.792**; GroupKFold 0.686+-0.095. Extended-without-NDBI R2=0.682 (above the full baseline — the gain doesn't ride on the quasi-circular predictor). HistGradientBoosting 0.760 ~ RF 0.765 and extended linear 0.727: the improvement is the spatial context, not the model class.
  - SHAP (TreeExplainer, spatial test set only): ndbi_foc3 (0.360 degC) > ndbi (0.355) > ndvi_foc3 (0.197) > dist_water_m (0.151) > ndvi (0.135). Neighbourhood versions of the drivers outrank cell values; coastal proximity carries real attribution (interpreted as proximity association, not a measured sea-breeze mechanism).
  - Standing caveats wherever these results appear: SHAP ranks model attributions, not physical causes (no causal claims); ndbi/ndbi_foc3 are quasi-circular (same 2024 Landsat composite as the target), bounded by the ablation; predictor years span 2020-2024 (same accepted year-mismatch limitation as the core pipeline); tiny LULC classes (cropland n=9, wetland n=3) have noise-level attributions.
